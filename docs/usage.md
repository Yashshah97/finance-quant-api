# Usage

```python
import finance_quant_api
```

Each module is self-contained; see docstrings for the API:

- `finance_quant_api.app` — Main application entry point
- `finance_quant_api.endpoints` — JSON endpoints for API
- `finance_quant_api.models` — Data models and schema definitions
- `finance_quant_api.services` — Business logic services and utility functions
- `finance_quant_api.tests_test_api` — Unit tests for the API
- `finance_quant_api.utils_validation` — Input validation and sanitization utilities
